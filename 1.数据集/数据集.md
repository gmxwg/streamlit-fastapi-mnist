### 0.前置知识
- 彩色图片是三通道，灰度图片是单通道
- 彩色图片是一个HWC三维矩阵，每一层分别表示红/绿/蓝的亮度
- ```
    img = Image.open('./test-dog.png')
    print(img) # img 本身不是图片实体，它只是一个 “指针 / 入口 / 索引”
    arr = np.array(img)
    print(arr.shape) #HWC
    ts = torch.tensor(arr)
    print(ts.shape) #HWC
    to_tensor = transforms.ToTensor()
    ts2 = to_tensor(img)
    print(ts2.shape) #CHW 
  ```

### 1.ToTensor
- 将输入的PIL Image 或 numpy数组（HWC，0-255）转换为PyTorch张量（CHW)
- 将像素值 $[0,255]$ (整数) 缩放到 $[0.0, 1.0]$

### 2.Normalize
- 对每个通道独立执行标准化（Z-score归一化）
- 公式: $output = (input - mean) \div std$ 
- 将原本$[0,1]$范围，变成正负都有、围绕0的数据，避免数值忽大忽小，防止梯度爆炸/消失，训练更稳
- 对于灰度图，只有一个平均值，一个标准差，RGB图一条通道各有一个平均值于标准差
